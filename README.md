# Experiment-10-BPSK-QPSK-and-DPSK
First-principles simulation of BPSK, Gray-coded QPSK and DPSK in Python and MATLAB, with no communications toolbox. Covers carrier phase offset, constellation rotation, phase trajectories, decision statistics and BER vs Eb/N0 against theory. Runs in Google Colab.
